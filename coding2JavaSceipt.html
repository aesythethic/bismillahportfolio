Object Constructor

function Player(name, marker) {
  this.name = name;
  this.marker = marker;
}

Call it by using new: 

const player = new Player("steve", "X");
console.log(player.name); // "steve"

Bila kita panggil new , object baru akan dicreate. Tak serupa kalu kita cuma panggil:Player("steve", "X")

Cara buat method untuk object pun berbeza dengan java: 
function Player(name, marker) {
  this.name = name;
  this.marker = marker;
  this.sayName = function() {
    console.log(this.name);
  };
}

const player1 = new Player("steve", "X");
const player2 = new Player("also steve", "O");
player1.sayName(); // logs "steve"
player2.sayName(); // logs "also steve"

Prototype

Semua object falam javaScript boleh linked ke object yang lain. If a propert or method is not found on the object, java script will look for in [[prototype]] Macam inheritance, kalau dah define dalam prototpe, object boleh ambik apa method yang ada dalm protytype.For example, if there was a .sayHello() function defined on the [[Prototype]], player1 can access the function just as if it was its own function - player1.sayHello(). But it’s not just player1 who can call the .sayHello() function, even player2 can call it, since it’s defined on its [[Prototype]].

Macammana nak letak something dalam prototype
Player.prototype.sayHello = function() {
  console.log("Hello, I'm a player!");
};

player1.sayHello(); // logs "Hello, I'm a player!"
player2.sayHello(); // logs "Hello, I'm a player!"
Code ni define sa yhelo function on player prototype. Jadi any player object created lepas ni boleh guna the prototype.
